# Workflow 5: Soporte Evolutivo

## Cuándo se usa
- Mantenimiento mensual de productos en producción.
- Iteración continua post-MVP.

## Pasos del ciclo mensual

```
Semana 1:
1. product-owner → review de feedback + métricas del mes anterior.
2. business-strategist → análisis de impacto comercial.
3. Definir backlog del mes.

Semana 2-3:
4. Workflow 3 (Desarrollo de Feature) para cada item del sprint.

Semana 4:
5. qa-engineer → testing integral.
6. devops-engineer → deploy a producción.
7. data-analyst → reporte de métricas post-deploy.
8. Update de MEMORIA-PROYECTO con aprendizajes.
```

## Skills involucradas
- Todas las anteriores del equipo.

## Output
- Producto actualizado mensualmente.
- Reportes de uso y performance.
- Backlog priorizado para próximo mes.

## Quality Gate
- Software Gate en cada deploy.
- Reporting Gate en reporte mensual.

## Cadencia
- Sprints quincenales o mensuales según cliente.
