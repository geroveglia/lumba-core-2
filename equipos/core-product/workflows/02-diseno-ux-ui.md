# Workflow 2: Diseño UX/UI Completo

## Cuándo se usa
- Después de spec funcional aprobada.
- Para construir/actualizar sistema de diseño.

## Pasos

```
1. ux-designer → flows + wireframes
2. analyst-functional → revisión funcional de UX
3. product-owner → validación de priorización en UX
4. ui-designer → diseño visual + estados + responsive
5. ui-designer → sistema de diseño documentado
6. product-auditor → audit UX/UI (UX/Product Gate)
7. PM o socio → aprobación
8. Validación con cliente
```

## Skills involucradas
- `ux-flow-design`
- Hereda `visual-system-design` de Core-Brand

## Output
- Flows completos.
- Wireframes hi-fi.
- Sistema de diseño documentado.
- Prototipo interactivo (si aplica).

## Quality Gate
- UX/Product Gate + Design Gate.

## Duración estimada
2-6 semanas según complejidad.
