# Skill: Google Ads Audit

## Checklist de auditoría

### Search terms
- [ ] Revisados última semana.
- [ ] Negativas actualizadas.
- [ ] No hay queries irrelevantes consumiendo budget.

### Conversion tracking
- [ ] Configurado.
- [ ] Eventos meaningful (compra/lead, no clicks).
- [ ] Atribución acordada con cliente.

### Quality Score
- [ ] Score promedio >5/10.
- [ ] Ad relevance correcta.
- [ ] Landing experience aceptable.

### Estructura
- [ ] Campañas separadas por tipo.
- [ ] Keywords agrupadas con sentido.
- [ ] Negatives actualizadas.

### Performance
- [ ] CTR por encima de benchmark.
- [ ] CPA dentro de KPI.
- [ ] Conversion rate sostenible.

Ver `google-ads-playbook.md` para lecturas.
