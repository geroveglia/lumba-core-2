# Skill: Growth Marketing Analysis

## Propósito
Analizar el funnel completo para identificar bottleneck.

## Proceso

### 1. Mapear funnel actual
- Acquisition: cuántos llegan.
- Activation: cuántos se enganchan.
- Conversion: cuántos convierten.
- Retention: cuántos vuelven.
- Revenue: cuánto generan.

### 2. Calcular conversion rates entre etapas
- Acquisition → Activation rate.
- Activation → Conversion rate.
- Conversion → Retention rate.

### 3. Identificar la fuga más grande
La etapa donde más usuarios se pierden = bottleneck.

### 4. Comparar con benchmarks
Si es posible, contra:
- Industria.
- Histórico del mismo cliente.

### 5. Proponer experimentos
Para atacar el bottleneck identificado.

Ver `growth-marketing-playbook.md` para framework.
