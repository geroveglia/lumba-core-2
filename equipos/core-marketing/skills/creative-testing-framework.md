# Skill: Creative Testing Framework

## Propósito
Testear creatives de manera estructurada (no tirar variantes random).

## Variables a testear (UNA por vez)

1. **Hook** (los primeros 3 segundos).
2. **Visual** (foto vs video, color, formato).
3. **Copy** (mensaje principal).
4. **Oferta** (cómo se presenta).
5. **CTA** (texto del botón).

## Setup
- Control: el creativo actual.
- Variante: cambia UNA variable.
- Audiencia: la misma.
- Budget: dividido equitativamente.

## Duración mínima
- 5-7 días.
- Mínimo 100 conversiones / cada lado para significancia.

## Decisión
- Si variante > control: ganador, escalar.
- Si control > variante: archivar variante con aprendizaje.
- Si empate: revisar guardrails.
