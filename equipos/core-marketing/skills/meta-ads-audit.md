# Skill: Meta Ads Audit

## Checklist de auditoría

### Configuración
- [ ] Pixel configurado y eventos passing.
- [ ] Conversions API si aplica.
- [ ] Custom audiences configuradas.
- [ ] Naming convention de campañas claro.

### Estructura
- [ ] Campañas separadas por objetivo.
- [ ] Ad sets sin overlap de audiencias.
- [ ] Exclusiones configuradas.

### Creativos
- [ ] Variantes suficientes (3+).
- [ ] Sin fatiga (frequency < 3 en cold).
- [ ] Hook en primeros 3 segundos.

### Tracking
- [ ] UTMs en todas las URLs.
- [ ] Eventos de conversión configurados.
- [ ] Atribución acordada con cliente.

Ver `meta-ads-playbook.md` para lecturas.
