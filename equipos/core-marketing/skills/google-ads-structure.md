# Skill: Google Ads Structure

## Estructura recomendada

### Campañas por tipo
- Branded.
- Generic / Category.
- Long-tail.
- Competitors (si estrategia).
- Performance Max (con supervisión).

### Ad groups
- Por subtema o producto.
- Keywords agrupadas por similitud de intent.

### Keywords
- Empezar con exact + phrase.
- Broad solo con negativas robustas.

### Negatives
- A nivel cuenta (generales).
- A nivel campaña (específicas).
- Actualizadas semanalmente.

Ver playbook para detalles.
