---

## 1. PROPÓSITO DE LA RED

Core-Marketing es la red de agentes especializada en **estrategia digital, contenido, performance, ecommerce y comunicación**.

Su función central: **resolver los 3 dolores del área de marketing**:

1. Pasar de ejecución a estrategia (no solo producir piezas).
2. Medir e interpretar (no solo reportar números).
3. Sostener producción creativa de calidad sin caer en fórmulas repetidas.

Atado al Principio 0: que cada campaña, contenido, email o reporte llegue al cliente con auditoría previa que asegure calidad estratégica.

## 6. WORKFLOWS

Core-Marketing tiene **8 workflows operativos**:

1. **Plan de marketing inicial** — diagnóstico → estrategia → plan.
2. **Campaña Meta Ads** — brief → estructura → creativos → lanzamiento.
3. **Campaña Google Ads** — keywords → ads → landing → optimización.
4. **Email marketing comercial** — segmentación → contenido → automatización.
5. **Calendario de contenido mensual** — pilares → calendario → producción.
6. **Reporte mensual con insights** — recolección → análisis → recomendaciones.
7. **Growth Reporting Sprint** — hipótesis → experimento → aprendizaje.
8. **Meta/Google Ads Audit** — diagnóstico de cuenta existente.

Ver detalles en `equipos/core-marketing/workflows/`.

## 8. CHECKLIST DE AUDITORÍA — MARKETING GATE

El `marketing-auditor` ejecuta este checklist según tipo de entregable.

### Para campañas de pauta
- [ ] KPIs claros antes de lanzar.
- [ ] Audiencias bien segmentadas.
- [ ] Pixel/conversiones configuradas.
- [ ] Creatividades alineadas a marca.
- [ ] Copys responden a la hipótesis del brief.
- [ ] Hay creatividad de control para testing.
- [ ] Tracking UTMs presente.

### Para email marketing
- [ ] Subject test definido.
- [ ] Preheader complementa el subject.
- [ ] CTA único y claro.
- [ ] Versión mobile optimizada.
- [ ] Links funcionando y trackeados.
- [ ] Lista correctamente segmentada.

### Para contenido / calendario
- [ ] Cada pieza responde a un pilar.
- [ ] Variedad de formatos.
- [ ] Tono coincide con la marca.
- [ ] Copys claros, no fórmulas.
- [ ] CTAs definidos donde corresponde.

### Para reportes
- [ ] Cada métrica tiene interpretación (no solo número).
- [ ] Se identificaron causas detrás de los números.
- [ ] Hay al menos 3 recomendaciones accionables.
- [ ] Conecta con objetivos del cliente.
- [ ] Tendencia comparada con mes anterior.

**Si falta algún checkbox, el entregable no sale.**
