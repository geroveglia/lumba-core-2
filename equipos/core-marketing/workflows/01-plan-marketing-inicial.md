# Workflow 1: Plan de Marketing Inicial

## Cuándo se usa
- Al iniciar una cuenta de marketing nueva.
- Al replantear estrategia de un cliente existente.
- Cada trimestre como revisión.

## Pasos

```
1. brand-researcher → contexto de mercado + competencia digital
2. data-analyst → diagnóstico de canales actuales (si los hay)
3. marketing-strategist → propuesta de plan integral con hipótesis y KPIs
4. devils-advocate → challenge a la estrategia
5. marketing-auditor → audit pre-presentación
6. PM / Vertical Lead humano → aprueba antes de cliente
7. Validación con cliente
8. Activación con especialistas (meta-ads-analyst, google-ads-analyst, etc.)
```

## Skills involucradas
- `marketing-diagnostic`
- `audience-builder`
- `attribution-model`

## Output
- Plan de marketing trimestral.
- Hipótesis estratégicas explícitas.
- KPIs por canal.
- Distribución sugerida de presupuesto.
- Calendario de activación.

## Quality Gate
- **Strategy Gate** + **Marketing Gate** al cierre.

## Duración estimada
1-2 semanas.
