# Workflow 7: Growth Reporting Sprint

## Cuándo se usa
- Sprint semanal de growth (recomendado para cuentas con experimentos activos).

## Pasos del sprint semanal

### Lunes
```
1. growth-marketing-specialist → review de tests activos
2. data-analyst → análisis de resultados parciales
3. growth-marketing-specialist → decisiones (scale/iterate/stop) sobre tests cerrados
```

### Martes - Jueves
```
4. growth-marketing-specialist → diseño de nuevos tests del sprint
5. Especialistas (meta/google/email) → producción de assets
6. marketing-auditor → audit de nuevos experimentos (Growth Gate)
```

### Viernes
```
7. Launch de tests del sprint
8. growth-marketing-specialist → documentación de aprendizajes de la semana
9. Update de MEMORIA-MARKETING con learnings
```

## Skills involucradas
- `growth-marketing-analysis`
- Template `growth-experiment-template.md`

## Output
- Tests activos del sprint.
- Documento de aprendizajes semanales.
- Backlog priorizado con ICE.

## Quality Gate
- **Growth Gate** por experimento.

## Filosofía
Experimentos fallidos son los más valiosos.
