# Workflow 4: Email Marketing Comercial

## Cuándo se usa
- Campaña de email puntual.
- Envío masivo a base.

## Pasos

```
1. marketing-strategist → brief + objetivo + audiencia
2. email-specialist → arquitectura del email + segmentación
3. copywriter → subject + preheader + body
4. identity-designer → diseño visual si aplica
5. email-specialist → setup técnico + tracking
6. marketing-auditor → audit (Marketing Gate)
7. PM o Vertical Lead → aprobación humana antes de envío
8. Envío
9. data-analyst → reporte de performance
```

## Skills involucradas
- `email-architecture`
- `audience-builder`

## Output
- Email enviado.
- Reporte de open rate, CTR, conversiones.

## Quality Gate
- **Marketing Gate** pre-envío.

## Regla crítica
Ningún email masivo se envía sin aprobación humana.
