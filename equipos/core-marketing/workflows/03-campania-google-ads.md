# Workflow 3: Campaña Google Ads

## Cuándo se usa
- Lanzamiento de campaña nueva en Google Ads.
- Reestructuración de cuenta existente.

## Pasos

```
1. marketing-strategist → brief + KPIs
2. google-ads-analyst → research de keywords + intent
3. google-ads-analyst → estructura de cuenta + match types + negativas
4. copywriter → variantes de ad copy
5. ecommerce-manager / equipo → revisión de landing pages
6. google-ads-analyst → conversion tracking + UTMs
7. marketing-auditor → audit pre-launch
8. Aprobación humana + Martín si budget >USD 1000
9. Lanzamiento
10. google-ads-analyst → revisión semanal de search terms + negativas
11. data-analyst → reporte mensual
```

## Skills involucradas
- `google-ads-structure`
- `google-ads-audit`

## Output
- Cuenta de Google Ads activa.
- Lista de keywords negativas inicial.
- Plan de optimización semanal.

## Quality Gate
- **Paid Media Gate** pre-launch.

## Validación humana
- Antes de lanzar (siempre).
- Si presupuesto >USD 1000 → también Martín.
