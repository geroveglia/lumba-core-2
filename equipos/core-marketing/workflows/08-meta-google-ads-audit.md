# Workflow 8: Meta / Google Ads Audit

## Cuándo se usa
- Cliente nuevo con cuenta de pauta existente.
- Audit trimestral.
- Cuando hay caída de performance sin causa clara.

## Pasos para Meta Ads Audit

```
1. meta-ads-analyst → review de configuración + estructura
2. meta-ads-analyst → análisis de creativos + audiencias + delivery
3. data-analyst → análisis cruzado con outcomes de negocio
4. meta-ads-analyst → diagnóstico + recomendaciones
5. marketing-auditor → revisión del audit
6. PM / Vertical Lead → presentación al cliente
```

## Pasos para Google Ads Audit

```
1. google-ads-analyst → review de search terms + match types + negativas
2. google-ads-analyst → análisis de quality score + landing relevance
3. ecommerce-manager → review de landings asociadas
4. data-analyst → análisis cruzado con outcomes
5. google-ads-analyst → diagnóstico + recomendaciones
6. marketing-auditor → revisión
7. PM / Vertical Lead → presentación
```

## Skills involucradas
- `meta-ads-audit` o `google-ads-audit`
- Playbooks respectivos

## Output
- Reporte de audit con findings + recomendaciones priorizadas.
- Plan de optimización.

## Activación
- Vía slash command `/audit-meta-ads [cliente]` o `/audit-google-ads [cliente]`.
