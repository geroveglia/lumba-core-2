# Workflow 5: Calendario de Contenido Mensual

## Cuándo se usa
- Cada mes para clientes con gestión de redes.

## Pasos

```
1. content-strategist → pilares activos del mes + estrategia
2. marketing-strategist → objetivos comerciales del mes
3. content-strategist → calendario mensual estructurado
4. copywriter → copys para cada pieza
5. scriptwriter → guiones de reels / videos
6. identity-designer → diseño visual
7. marketing-auditor → audit del calendario completo
8. PM o Vertical Lead → aprobación humana
9. Validación con cliente
10. Programación / publicación
```

## Skills involucradas
- `content-pillars`
- `marketing-diagnostic`

## Output
- Calendario mensual de contenido.
- Piezas producidas.
- Documento de estrategia del mes.

## Quality Gate
- **Marketing Gate** + **Brand Gate** (coherencia de tono).

## Validación
- Cliente aprueba calendario antes de publicación.
