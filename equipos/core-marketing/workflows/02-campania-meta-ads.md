# Workflow 2: Campaña Meta Ads

## Cuándo se usa
- Lanzamiento de campaña nueva en Meta Ads.
- Recambio creativo importante.

## Pasos

```
1. marketing-strategist → brief de campaña con hipótesis + KPI
2. meta-ads-analyst → estructura de cuenta + audiencias
3. copywriter → variantes de copy (mínimo 3)
4. visual-director / identity-designer → variantes visuales si aplica
5. meta-ads-analyst → configuración técnica + tracking
6. marketing-auditor → audit pre-launch (Paid Media Gate)
7. Performance specialist humano + Martín → aprobación final si presupuesto >USD 1000
8. Lanzamiento
9. meta-ads-analyst → monitoreo semanal
10. data-analyst → reporte post-campaña
```

## Skills involucradas
- `meta-ads-structure`
- `meta-ads-audit`
- `creative-testing-framework`

## Output
- Campaña activa en Meta Ads.
- Documento de hipótesis + KPIs.
- Reporte post-campaña.

## Quality Gate
- **Paid Media Gate** pre-launch.
- **Reporting Gate** post-campaña.

## Validación humana obligatoria
- Antes de lanzar (siempre).
- Si presupuesto >USD 1000 → también Martín.
