# Workflow 6: Reporte Mensual con Insights

## Cuándo se usa
- Cada mes, para clientes activos de marketing.

## Pasos

```
1. data-analyst → recolección de data de todos los canales
2. meta-ads-analyst → análisis de performance Meta
3. google-ads-analyst → análisis de performance Google
4. email-specialist → análisis de email si aplica
5. ecommerce-manager → análisis de tienda si aplica
6. data-analyst → consolidación con estructura "qué pasó / qué significa / qué lo causa / qué hacer"
7. marketing-strategist → recomendaciones estratégicas
8. marketing-auditor → audit obligatorio (Reporting Gate)
9. PM o Vertical Lead → aprobación humana
10. Presentación al cliente
```

## Skills involucradas
- `report-with-insights`
- `marketing-reporting`
- `attribution-model`

## Output
- Reporte mensual con insights.
- Recomendaciones para el mes siguiente.

## Quality Gate
- **Reporting Gate** obligatorio.

## Regla de hierro
Un reporte con números sin interpretación NO pasa el gate.
