## 1. PROPÓSITO DE LA RED

Core-Brand es la red de agentes que sirve a los proyectos de **identidad, posicionamiento, narrativa y comunicación de marca**.

Su función central: **reducir la corrección posterior en branding** (Principio 0 de Lumba Core).

---

## 2. SERVICIOS QUE CUBRE

Basado en los servicios reales de Lumba en branding:

- Diagnóstico de marca.
- Rebranding.
- Estrategia de marca.
- Posicionamiento y diferenciación.
- Identidad visual completa.
- Logotipo y variantes.
- Sistema gráfico.
- Paleta cromática.
- Tipografías.
- Manual de marca / brandbook.
- Tono de voz y storytelling.
- Claims y mensajes principales.
- Aplicaciones de marca.
- Packaging.
- Presentaciones institucionales.
- Workshops de marca.
- Benchmark y análisis competitivo.
- Misión, visión, valores, propósito.

## 5. WORKFLOWS

Core-Brand tiene **6 workflows operativos**:

### Workflow 1: Diagnóstico de marca

```
1. brand-researcher → recolecta info del cliente + benchmark
2. brand-strategist → análisis interno + diagnóstico
3. brand-differentiator → mapeo competitivo
4. brand-auditor → revisa coherencia y completitud
5. Humano (PM o socio) → aprueba antes de presentar
```

### Workflow 2: Workshop estratégico

```
1. workshop-facilitator → prepara guía + preguntas
2. Humano → facilita workshop con cliente
3. workshop-facilitator → estructura outputs del workshop
4. brand-strategist → destila estrategia base
5. brand-auditor → revisa coherencia con info previa
6. Humano → aprueba antes de presentar
```

### Workflow 3: Identidad visual

```
1. visual-director → propone territorios visuales
2. Humano → valida dirección con cliente
3. identity-designer → genera propuestas
4. brand-auditor → revisa coherencia con estrategia
5. visual-director → presenta opciones curadas
6. Humano → aprueba propuesta final
7. identity-designer → desarrolla sistema completo
8. brand-auditor → QA final
```

### Workflow 4: Manual de marca

```
1. brandbook-builder → genera estructura del manual
2. identity-designer + brand-voice-writer → aportan contenido
3. brand-auditor → revisa coherencia interna
4. Humano → aprueba versión final
```

### Workflow 5: Brand differentiation audit

```
1. brand-researcher → recolecta info de competencia
2. brand-differentiator → identifica diferenciales reales
3. brand-strategist → valida que sean accionables
4. brand-auditor → revisa coherencia
5. Humano → valida y aplica en estrategia
```

### Workflow 6: Visual identity review (auditoría rápida)

```
1. visual-director → revisa pieza visual contra sistema
2. brand-auditor → ejecuta checklist completo
3. Si pasa → entrega
4. Si no pasa → vuelve a identity-designer con feedback
```

## 6. CHECKLIST DE AUDITORÍA — BRAND GATE

Ningún entregable de branding sale sin pasar este checklist. Lo ejecuta `brand-auditor`.

### Estratégico
- [ ] Responde al posicionamiento definido.
- [ ] Mensaje alineado con tono de voz.
- [ ] Conecta con territorios conceptuales aprobados.
- [ ] Diferencia de competencia analizada.
- [ ] Resuelve el problema de marca del diagnóstico.

### Visual
- [ ] Respeta sistema visual aprobado.
- [ ] Usa paleta cromática oficial.
- [ ] Usa tipografías del sistema.
- [ ] Jerarquía visual clara.
- [ ] Aplicación correcta del logotipo.

### Coherencia
- [ ] Conecta con entregables anteriores del mismo cliente.
- [ ] Memoria del cliente al día.
- [ ] No contradice criterios aprobados previamente.

### Brief
- [ ] Cumple objetivo del brief.
- [ ] Respeta restricciones.
- [ ] Decisor final identificado.

**Si CUALQUIER checkbox queda sin marcar, el entregable no sale.**

| Dolor del área | Cómo Core-Brand lo resuelve |

5. Identidad visual completa.
6. Manual de marca + aplicaciones.
7. Packaging si aplica.

### Caso 2: Naming + identidad para producto nuevo

**Flujo más corto:**
1. Brief estratégico.
2. Naming (con skill `naming-method`).
3. Identidad visual.
4. Manual mínimo.

**Tiempo:** 4-6 semanas.

### Caso 3: Audit de marca existente

**Flujo de audit:**
1. Análisis de comunicaciones actuales.
2. Benchmark de competencia.
3. Detección de inconsistencias.
4. Recomendaciones de ajuste.

**Tiempo:** 2-3 semanas.

## 9. MEMORIA POR CLIENTE EN CORE-BRAND

Cada cliente de branding tiene `MEMORIA-MARCA.md` que se mantiene viva durante toda la relación.

Contenido mínimo:

- Posicionamiento aprobado.
- Tono de voz definido.
- Paleta cromática oficial.
- Tipografías del sistema.
- Reglas de uso del logotipo.
- Aplicaciones aprobadas.
- Decisiones rechazadas + motivo.
- Preferencias del cliente.
- Lecciones aprendidas.

Sin esta memoria, cada nuevo entregable es un reinicio.
