# Workflow 6: Visual Identity Review (Auditoría Rápida)

## Cuándo se usa
- Para revisar una pieza visual existente.
- Audit rápido sin replantear sistema.
- Validación pre-entrega de pieza individual.

## Pasos

```
1. visual-director → revisa pieza visual contra sistema vigente
2. brand-auditor → ejecuta checklist completo (skill brand-audit-checklist)
3. Decisión:
   - ✅ Pasa → entrega
   - ⚠️ Necesita ajustes menores → vuelve a identity-designer
   - ❌ Falla crítica → replanteo
```

## Skills involucradas
- `brand-audit-checklist`
- `visual-system-design`

## Output
- Reporte de audit (JSON Schema D).
- Pieza aprobada o feedback específico.

## Quality Gate
- **Brand Gate** + **Design Gate**.

## Duración estimada
30-60 minutos por pieza.
