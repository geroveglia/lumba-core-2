# Workflow 1: Diagnóstico de Marca

## Cuándo se usa
- Al iniciar un proyecto de branding nuevo.
- Para audit de marca existente.
- Antes de plantear estrategia.

## Pasos

```
1. brand-researcher → recolecta info del cliente + benchmark de competencia
2. brand-strategist → análisis interno + diagnóstico estructurado
3. brand-differentiator → mapeo competitivo + detección de oportunidades
4. brand-auditor → revisa coherencia y completitud
5. PM o socio → aprueba antes de presentar al cliente
```

## Skills involucradas
- `brand-diagnostic`
- `benchmark-framework`

## Output
- Documento de diagnóstico de marca.
- Mapeo de competencia.
- Hipótesis estratégicas.
- Próximos pasos recomendados.

## Quality Gate
- **Strategy Gate** al cierre.

## Duración estimada
1-2 semanas.

## Validación humana
- PM o socio antes de presentar al cliente.
