# Workflow 3: Identidad Visual

## Cuándo se usa
- Después de estrategia aprobada.
- Para crear identidad desde cero.
- Para rebranding visual.

## Pasos

```
1. visual-director → propone territorios visuales (3 caminos típicamente)
2. Humano (Vertical Lead) → valida dirección con cliente
3. identity-designer → genera propuestas (1 por territorio)
4. brand-auditor → revisa coherencia con estrategia
5. visual-director → curaduría de opciones
6. Humano (cliente) → aprueba propuesta final
7. identity-designer → desarrolla sistema completo
8. brand-auditor → QA final del sistema
9. PM o socio → aprueba antes de entrega final
```

## Skills involucradas
- `visual-system-design`
- `brand-audit-checklist`

## Output
- 3 territorios visuales con justificación.
- Propuestas iniciales (mockups).
- Sistema visual completo aprobado.
- Archivos editables organizados.

## Quality Gate
- **Design Gate** al cierre del sistema.
- **Brand Gate** antes de entrega al cliente.

## Duración estimada
3-6 semanas.

## Validación humana
- Cliente valida dirección antes de desarrollar sistema completo.
- PM o socio antes de entrega final.
