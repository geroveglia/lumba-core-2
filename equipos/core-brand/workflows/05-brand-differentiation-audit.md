# Workflow 5: Brand Differentiation Audit

## Cuándo se usa
- Antes de cerrar posicionamiento.
- En audits de marca existente.
- Cuando una propuesta se siente "como cualquiera".

## Pasos

```
1. brand-researcher → recolecta info detallada de competencia
2. brand-differentiator → identifica diferenciales reales vs falsos
3. brand-strategist → valida que sean accionables
4. brand-auditor → revisa coherencia con posicionamiento
5. Humano → valida y aplica en estrategia
```

## Skills involucradas
- `benchmark-framework`
- `positioning-canvas`

## Output
- Matriz de diferenciación.
- Lista de diferenciales reales.
- Lista de "diferenciales falsos" a evitar.
- Recomendación de cómo articular la diferenciación.

## Quality Gate
- **Strategy Gate**.

## Duración estimada
3-5 días.
