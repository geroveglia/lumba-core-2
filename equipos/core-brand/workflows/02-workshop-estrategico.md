# Workflow 2: Workshop Estratégico

## Cuándo se usa
- Después del diagnóstico de marca.
- Para extraer información del cliente.
- Para alinear visión con cliente.

## Pasos

```
1. workshop-facilitator → prepara guía + preguntas + ejercicios
2. Humano (Vertical Lead) → facilita workshop con cliente
3. workshop-facilitator → estructura outputs del workshop
4. brand-strategist → destila estrategia base
5. brand-auditor → revisa coherencia con info previa
6. PM o socio → aprueba síntesis antes de presentar al cliente
```

## Skills involucradas
- `workshop-facilitator`
- `brand-diagnostic`

## Output
- Guía estructurada del workshop.
- Documento de síntesis (máx 48h después del workshop).
- Hipótesis estratégicas refinadas.
- Decisiones tomadas / pendientes.

## Quality Gate
- **Strategy Gate** al cierre.

## Duración estimada
- Preparación: 2-3 días.
- Workshop: 2-4 horas.
- Síntesis: 1-2 días.
