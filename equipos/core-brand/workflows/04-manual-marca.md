# Workflow 4: Manual de Marca

## Cuándo se usa
- Después de identidad visual aprobada.
- Después de tono de voz definido.
- Para consolidar todo en un documento.

## Pasos

```
1. brandbook-builder → genera estructura del manual
2. identity-designer → aporta archivos + reglas visuales
3. brand-voice-writer → aporta tono + ejemplos de copy
4. brand-strategist → aporta plataforma estratégica
5. brandbook-builder → consolida en versión completa
6. brand-auditor → revisa coherencia interna
7. PM o socio → aprueba versión final
```

## Skills involucradas
- `brandbook-template`
- `visual-system-design`
- `tone-of-voice-builder`

## Output
- Brandbook completo (versión PDF + markdown).
- Brandbook lite (cheatsheet).
- Archivos editables organizados.

## Quality Gate
- **Brand Gate** antes de entrega.

## Duración estimada
1-2 semanas (después de tener identidad y tono).
