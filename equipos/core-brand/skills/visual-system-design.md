# Skill: Visual System Design

## Propósito

Reglas para construir un sistema visual coherente, escalable y diferenciado.

## Componentes mínimos

1. **Logotipo + variantes**
   - Principal.
   - Vertical / horizontal.
   - Monocromo.
   - Reducción mínima.
   - Zona de respeto.

2. **Paleta cromática**
   - 1 color primario.
   - 2-3 secundarios.
   - 2-3 neutros (blanco, gris, negro).
   - Definición HEX + RGB + CMYK + Pantone si aplica.

3. **Tipografías**
   - 1 display (para títulos).
   - 1 texto (para cuerpo).
   - Máximo 2 fuentes en total.
   - Sistema de tamaños / pesos.

4. **Sistema gráfico**
   - Patrones / texturas (opcional).
   - Iconografía (estilo definido).
   - Fotografía / ilustración (style guide).

## Reglas

- **NO usar** más de 2 tipografías.
- **NO usar** más de 5-6 colores.
- **SÍ definir** reglas de uso explícitas.
- **SÍ probar** en aplicaciones reales antes de cerrar.

## Test del sistema

El sistema funciona si:
- Funciona en blanco y negro.
- Funciona en miniatura (16px).
- Funciona impreso y digital.
- Funciona en distintos formatos (cuadrado, vertical, horizontal).
- Es reconocible sin el logotipo.
