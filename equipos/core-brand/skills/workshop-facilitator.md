# Skill: Workshop Facilitator

## Propósito

Estructurar workshops estratégicos con clientes para extraer información clave de manera eficiente.

## Tipos de workshops

### Workshop 1: Discovery (2-3 horas)
- Historia de la empresa.
- FODA actual.
- Audiencia objetivo.
- Competencia percibida.
- Expectativas del proyecto.

### Workshop 2: Posicionamiento (2-3 horas)
- Propuesta de valor.
- Diferenciales reales.
- Personalidad de marca.
- Tono y voz.
- Territorios conceptuales.

### Workshop 3: Identidad visual (2 horas)
- Referencias estéticas.
- Likes / dislikes visuales.
- Aplicaciones críticas.
- Restricciones técnicas.

## Estructura mínima de cada workshop

1. **Apertura (10 min)** — contexto, objetivo, dinámica.
2. **Calentamiento (15 min)** — ejercicio bajo de fricción.
3. **Núcleo (60-90 min)** — ejercicios principales.
4. **Síntesis (20 min)** — consolidación.
5. **Próximos pasos (10 min)** — qué sigue.

## Output del workshop

Documento estructurado con:
- Información recolectada.
- Decisiones tomadas.
- Decisiones pendientes.
- Hipótesis emergentes.
- Próximos pasos acordados.

## Reglas

- **NO inventar** respuestas del cliente.
- **SÍ grabar** (con permiso) para no perder data.
- **SÍ entregar** síntesis al cliente máximo 48h después.
