# Skill: Benchmark Framework

## Propósito

Estructura para analizar competencia directa e indirecta de manera comparable.

## Proceso

1. **Identificar 5-10 competidores** (directos + indirectos).
2. **Mapear cada uno** según:
   - Posicionamiento explícito.
   - Tono de voz.
   - Identidad visual.
   - Propuesta de valor declarada.
   - Audiencia objetivo aparente.
   - Canales que usa.
   - Fortalezas observables.
   - Debilidades observables.
3. **Construir matriz comparativa**.
4. **Identificar espacios vacíos** (oportunidades).
5. **Detectar patrones** de la categoría (qué hacen TODOS).

## Output

- Matriz de competidores.
- Mapa de espacios vacíos.
- Análisis de patrones de categoría.
- Recomendaciones estratégicas.

## Reglas

- **SÍ citar fuentes** de cada hallazgo.
- **NO inventar** competidores.
- **SÍ distinguir** entre "lo que dicen" y "lo que hacen".
