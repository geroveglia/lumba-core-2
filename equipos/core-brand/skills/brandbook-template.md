# Skill: Brandbook Template

## Propósito

Estructura estándar para manuales de marca de Lumba.

## Estructura completa

### 0. Portada
- Nombre de la marca.
- Versión.
- Fecha.

### 1. Quiénes somos
- Manifiesto / esencia.
- Misión / visión / valores.
- Posicionamiento.

### 2. Identidad visual
- Logotipo + variantes + reglas.
- Zona de respeto.
- Reducción mínima.
- Usos correctos / incorrectos.
- Paleta cromática (HEX + RGB + CMYK).
- Tipografías + jerarquía + pesos.
- Sistema gráfico.
- Iconografía.

### 3. Tono de voz
- Atributos.
- Anti-atributos.
- Reglas operativas.
- Ejemplos sí / no.
- Aplicaciones por contexto.

### 4. Aplicaciones
- Redes sociales (templates).
- Email.
- Web.
- Papelería si aplica.
- Packaging si aplica.

### 5. Qué hacer y qué NO hacer
- Ejemplos visuales.
- Ejemplos de copy.

### 6. Anexos
- Archivos descargables.
- Contacto del equipo de Lumba.

## Versiones

- **Brandbook completo** — PDF de 30-60 páginas.
- **Brandbook lite** — cheatsheet de 1-2 páginas.
- **Brandbook digital** — versión web navegable.

## Reglas

- **SÍ versionar** (v1.0, v1.1, etc.).
- **SÍ documentar** fecha de última actualización.
- **SÍ marcar** secciones pendientes de completar.
